## About

**Roomi** is a mobile roommate-finder app for university students built with **React Native**, **Expo**, and **Firebase**. It uses a swipe-based matching flow, voice input for onboarding, and Firebase Cloud Functions for its backend to connect students looking for compatible roommates or available rooms near campus.

## Features

- Swipe-based roommate discovery with like/pass matching flow
- Voice input support during onboarding via React Native Voice and Expo Speech
- In-app chat with matched users powered by Firebase Firestore
- Room listings with photos, pricing, and location details
- User profiles with university, major, lifestyle preferences, and budget
- Compatibility-based matching using preference data collected at onboarding
- Firebase Cloud Messaging push notifications for new matches and messages

## Technology Stack

- **Mobile**: React Native, Expo, TypeScript
- **Backend**: Firebase Authentication, Cloud Firestore, Firebase Storage, Firebase Cloud Functions, Firebase Cloud Messaging
- **Voice**: React Native Voice, Expo Speech, Expo AV
